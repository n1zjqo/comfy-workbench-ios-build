# Comfy Workbench for iOS

## 0.6.4 动态参考素材与结果展示（build 13，已构建）

- 参数页从当前工作流的有效上传输入生成“参考素材”区。单图/单视频显示大预览，多份横向素材独占一行，竖向与方形素材并排；预览依据实际比例完整显示。混合工作流按图片、视频、音频分组，音频提供紧凑的试听入口；纯文字工作流不显示素材区。
- 每份素材绑定节点 ID 与输入键。能直接确认的首帧、尾帧显示用途，共用一个加载节点的素材保持同一入口。可从相册选择图片或视频、从文件选择对应类型，单独替换或清空；保存后才改参数，沿用撤销与草稿。清空不删除服务器原文件，必填输入仍需重新选择后运行。
- 创作页删除用于换底图的图片按钮；参考素材上传统一在参数页。保留作品详情中主动设为背景的操作。
- 默认展示工作流末端保存的结果，中间保存、预览与比较器图放到可展开的其他输出中。真实批次及独立成图分支保持多张；此规则不改变服务器任务数量与工作流。
- 生成提交、历史查询、素材访问和节点检查共享连接状态与客户端。回前台和进入连接页只作轻量状态检查；旧的失败探测不能覆盖更新的成功连接。
- 保持 iOS 15.0、原有数据与服务协议。此版本没有修改 OfficeBridge 或 Windows Companion。

当前限制：识别的是 JSON 已有的上传节点，不自动新增或连接 H3 动态端口；纯路径输入仍是路径编辑。支持标准上传标记及 VHS 视频/音频上传节点，参照 [VHS 视频加载实现](https://github.com/Kosinkadink/ComfyUI-VideoHelperSuite/blob/main/videohelpersuite/load_video_nodes.py)与[音频加载实现](https://github.com/Kosinkadink/ComfyUI-VideoHelperSuite/blob/main/videohelpersuite/nodes.py)。服务器已有的素材需要可访问才能预览；视频播放受 iOS 解码能力限制。单份上传上限 150 MB，照片上限 4000 万像素。

## 0.5.0 多设备剪贴板

- 底部“同步”页：文字、PNG 图片、来源设备、历史记录、待发送队列，支持一键用作提示词或设为聊天底图。
- 配对新的 Windows LanAI Companion：在电脑启动中心，开启 2 分钟单次配对码；每台设备独立令牌，可在电脑端移除。
- 手动填写局域网和公网 HTTPS 双地址，优先局域网，失败自动尝试公网；每次切换校验中心 ID，不把令牌发送到不匹配的中心。仅信任自己填写的局域网；中心 ID 校验不替代 TLS。
- iOS 前台自动发送/自动接收可分别开启；返回前台补同步。iOS 后台挂起或锁屏期间不保证持续同步，TrollStore 安装不会改变这个实现范围。
- 断网待发送保留编号，恢复后重试；中心持久化去重；接收到的内容不自动回传。首次配对仅加载历史，不覆盖当前剪贴板；本地新复制优先。
- 单条文字最大 256 KB，PNG 最大 5 MB / 2400 万像素；历史最多 100 条、32 MB，待发送最多 30 条、32 MB；超过 7 天的待发送需重新发送。
- 令牌保存在 Keychain；iOS 本地历史/待发送启用完整文件保护。Windows 端使用当前用户的 DPAPI 加密保存。公网使用 HTTPS；未实现端到端加密。
- DDNSTO 验证入口支持手动打开公网网页并返回重试。需要自行配置可到达同一中心的 HTTPS 转发；未配置公网域名时只可局域网使用。
- 使用新的 `/v1` 协议，不兼容旧 LanAI 设备；旧 AI 聊天、共享文件尚未迁入这一版。

- 本轮原生自动检查验证铺满视图、原比例图片区域、真实模糊组件、边框路径和持久化撤销/草稿恢复。测试使用合成图像和数据；iOS 模拟器测试不能替代 XS 上的材质、手势和 GPU 运行验收。

## 0.3.0 交互画布

- “应用 → 打开画布”进入全屏画布。普通 JSON 保留节点坐标、尺寸与连接；API JSON 没有原始坐标，按连接关系自动布局。
- 深海色点阵背景、玻璃工具条、曲线连线和选中高光；双指缩放、单指移动、搜索定位、上下游跳转、一键总览与可点击的小地图。
- 点击节点，在底部面板编辑提示词、种子、尺寸、模型等参数。参数页和画布共用同一份工作流；连接输入通过上游节点修改。

**从旧版升级：** 旧版已转换为 API 的画布副本没有保存原始坐标。要还原原布局，请重新导入原始画布 JSON；已有 API 工作流可以直接使用自动布局。

## 功能

- 导入、保存与导出 ComfyUI API JSON，保留输入类型、完整 UInt64 种子及节点连接。
- AI 应用式参数面板，可固定常用参数并查看编辑字面值输入。通过 `/object_info` 获取模型、枚举和数值范围。
- 全屏交互画布使用默认节点类型名，保留普通 JSON 的布局，支持缩放、定位与参数编辑。
- 对话内容发送到明确选定的提示词入口，记录任务状态、文字、图片与视频结果。
- 右滑清屏、左滑恢复；保留底图与毛玻璃边框，并提供恢复按钮。
- 相册底图、作品底图、系统分享以及按输入字段上传素材。
- HTTP、WebSocket、Basic Auth、Keychain、代理子路径及任务恢复。
- 取消属于当前任务的待执行队列项；不能确认定向中断能力时不调用全局中断。
- 前台恢复后查询队列和历史。iOS 后台挂起期间不保证持续下载。
- 按需随机种子；可将具名参数中的 `control_after_generate=randomize` 转成每次生成随机种子配置。

画布 JSON 转换需要从用户自己的服务器读取节点定义。转换器支持具名 widget、Set/Get、Reroute、类型明确的旁路、V3 动态参数及 VHS 编码选项。遇到缺失节点、未知参数、断开输入或不确定旁路会停止并解释原因；也可在 ComfyUI 中导出 API 格式后导入。位置参数只支持明确列出的标准节点布局，并核对参数数量和服务器定义；不保证支持任意第三方扩展或子图。

## 使用

1. 构建并安装应用后，进入“连接”，填写手机可以访问的 ComfyUI 地址。地址默认留空；`http://192.168.1.20:8188` 仅为格式示例，需替换为自己的地址。
2. 如服务器需要 Basic Auth，填写用户名与密码。选择“测试连接并保存”，并允许本地网络访问。
3. 在“应用”点“+”，选择“从文件导入”或“从服务器读取”。点“打开画布”缩放查看，点击节点编辑参数；通过“配置面板”固定常用字段并指定聊天提示词入口。普通画布需连接服务器并检查运行条件后才能生成。
4. 在“应用”运行当前参数，或在“对话”发送新提示词。
5. 最新生成图片会自动成为背景，也可手动选择底图。右滑清屏，左滑或点左箭头返回；打开作品后轻触图片显示分享等操作。

本仓库不提供用户工作流、模型、提示词、生成素材或服务器凭据。`Preview.html` 是无需联网的交互设计预览，使用虚构示例及 CSS 图形，不是原生 App 截图，不会提交生成任务。

## DDNSTO 与服务器工作流

DDNSTO 地址由用户手动填写，代码不预设外网域名。“打开网页验证”打开当前配置的 HTTPS 地址；App 不读取浏览器密码或 Cookie。按 [DDNSTO 官方说明](https://doc.linkease.com/zh/guide/ddnsto/scenarios/authentication.html)，验证可能因到期或公网 IP 改变失效；浏览器与 App 需要相同网络出口。本版没有真实 DDNSTO 域名可测试，不能保证所有代理配置均兼容。

服务器工作流列表使用 ComfyUI 的 `/users`、`/userdata` 只读接口，只显示 ComfyUI 工作流管理中已保存的文件。浏览器临时画布、任意磁盘目录或未启用此接口的旧服务器不会自动显示。多用户环境需选择已有用户；不会创建账号或修改服务器配置。

## 构建

工程无需第三方 Swift 依赖。GitHub Actions 仅手动触发，不自动发布 Release。

1. 将工程内容放在自己的 GitHub 仓库根目录，保留 `.github/workflows/ios-build.yml`。
2. 在 Actions 中选择 **Build iOS 15 IPA** → **Run workflow**。
3. 工作流将执行结构检查、`swift test`、已安装 iPhone 模拟器上的原生测试和 arm64 iPhone 构建，进行 ad-hoc 签名并核对包结构与最低系统版本。
4. 只有构建成功后，才会出现包含 `ComfyWorkbench.ipa` 的 `ComfyWorkbench-iOS15` artifact。

构建脚本配置为 macOS 15 / Xcode 16.4。IPA 面向已有兼容 [TrollStore](https://github.com/opa334/TrollStore) 环境，不用于 App Store 分发，不添加私有权限、JIT 或越狱功能。请自行确认设备与安装环境兼容性。

在具备相应 Xcode 环境的 Mac 上：

```bash
swift test
bash scripts/build-ipa.sh
```

结构检查：

```bash
python3 scripts/verify-source.py
```

结构检查仅验证文件、JSON、plist、源文件引用与构建配置。0.4.0 CI 的 69 项核心/网络测试和 5 项原生测试已通过，覆盖坐标、布局、参数同步、导出、连接保护、范围校验、执行事件、编辑历史与图片布局。测试覆盖 JSON/大整数/连接保持、画布转换、HTTP 错误、任务恢复、认证/路径和取消范围。自动化测试使用合成数据，不代替真实服务器和设备验收。
